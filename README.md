# نظام إدارة المجلة

مجلة نظريات وتطبيقات التربية البدنية وعلوم الرياضة - كلية علوم الرياضة - جامعة مدينة السادات

تطبيق ويب في ملف واحد (`index.html`) لإدارة الأبحاث والمحكّمين والرسوم والإيرادات مع تصدير Excel.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `journal-app`).
2. ارفع كل محتويات هذا المجلد (Add file > Upload files).
3. من Settings > Pages اختر Branch: `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://USERNAME.github.io/journal-app/`

## تنبيهات مهمة
- **البيانات تُحفظ داخل متصفح كل مستخدم (localStorage)**، فلا تتشارك بين المسؤول والمحرر على أجهزة مختلفة. استخدم النسخة الاحتياطية (JSON) من الإعدادات لنقل البيانات.
- كلمات السر تنظيم للصلاحيات فقط وليست حماية حقيقية. الحسابات الافتراضية (`admin/admin123` و`editor/editor123`) ظاهرة في الكود العام، فلا تخزّن بيانات حساسة في النسخة المنشورة.
- للاستخدام الفعلي بعدة مستخدمين وبيانات مشتركة تلزم قاعدة بيانات وخادم (مثل Firebase أو Supabase).
- تصدير Excel يحتاج اتصالًا بالإنترنت لتحميل مكتبة SheetJS من cdnjs، وبدونه يُصدَّر CSV.

## الملفات
- `index.html`: التطبيق كاملًا (الشعارات مضمّنة داخله).
- `assets/`: نسخة أصلية من الشعارات.
